Welcome to the firewall, Packet-Maiden. Your mission is to 
maintain the uplink against the aggressive manifestations 
of the network. Stay synced, stay fast, and avoid the 
bandwidth throttle.

------------------------------------------------------------
ARCADE CONTROLS
------------------------------------------------------------
* ARROW KEYS / WASD : Navigate the packet-stream (Movement)
* [Z] / SPACEBAR    : Initiate Data Upload (Fire)
* [X]               : Deploy System Bomb (Emergency Reset)
* [SHIFT]           : Focus Link (Precision move + Core Hitbox)
* [T]               : Toggle Frame Cap (Start Screen Only)
                      (60FPS Arcade vs Uncapped Lunatic)

------------------------------------------------------------
CORE MECHANICS
------------------------------------------------------------

1. THE SIGNAL MODULATION SYSTEM
Your weapon strength is tied directly to your GRAZE STREAK.
As you dodge bullets, your bandwidth expands:
* Standard Link (0-4 Streak): Original wide-spread pattern.
* High Speed Data (5-9 Streak): Increased fire rate.
* Shielded Overclock (10+ Streak): While WiFi Shield is active, 
  fire Triple Heavy Beams (Double Damage to bosses).

2. WIFI TETHER & BORDER ALARM
The network has physical boundaries. Staying outside triggers
the STALLING PENALTY:
* Exiting the screen causes the border to FLASH RED.
* Staying off-screen > 90 frames = -500 points + auto-tether.

3. SHIELD BREAK & RECOVERY
* SHIELD BREAK EFFECT: A cyan shockwave pulses when the graze shield 
  is consumed, providing 60 frames of invulnerability.
* GOLD MEDALS (M): Dropped by generic packets. (+500 points)
* MAGENTA BOMBS (B): Rare drops. (Replenishes System Bombs)

NEW GAME+ (LINK ITERATIONS)
------------------------------------------------------------
Defeating SHOTGUN-KO triggers a SERVER RESET. The game loops 
back to Wave 1 with these OVERCLOCKED changes:

* DIFFICULTY: Bullet velocity +10% and HP +5% per iteration 
  (Capped for stability).
* FLAWLESS UPLINK: Earn +25,000 points if you clear a boss 
  without breaking your shield.
* FULL BUFFER BONUS: Clear all 3 bosses without using a Reconnect [C]
  to earn the +50,000 point bonus.
* PERSISTENCE: High scores and iterations save to Local Storage 
  and survive browser refreshes/F5.
